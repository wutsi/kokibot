# Skill: himalaya

Himalaya is a command-line email client that allows you to manage your emails directly from the terminal.
With Himalaya, you can read, send, and organize your emails without needing to open a web browser or email application.

[![](https://img.shields.io/badge/github-repo-blue?logo=github)](https://github.com/pimalaya/himalaya)
[![](https://img.shields.io/badge/rust-green.svg?logo=rust)](https://nodejs.org/)

## Setup

### Install

``` bash
brew install himalaya
```
