# Skill: pandoc

The universal document converter. Supports 60+ formats including Markdown, MS Word (DOCX), PDF, LaTeX, HTML5, EPUB,
Jupyter (IPYNB), etc.

[![](https://img.shields.io/badge/github-repo-blue?logo=github)](https://github.com/jgm/pandoc)

## Setup

In order to use this skill, you need to have `pandoc` installed, and `tectonic` installed for PDF conversions.

### Install Pandoc

``` bash
brew install pandoc
```

### Install Tectonic

``` bash
brew install tectonic
``````
